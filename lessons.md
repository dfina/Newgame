# Lessons

- **Egress policy blocks all research hosts; WebSearch is the only channel** — curl/WebFetch get 403 on wikipedia/thesportsdb/fifa.com (proxy CONNECT denials, confirmed via proxy status). All research must go through WebSearch; TheSportsDB IDs only obtainable when its URLs surface in results, so runtime crest lookup must work by club-name search with local caching, IDs optional enrichment.
- **Search backend ignores site: operator** — don't build agent strategies around site-scoped queries; use targeted natural queries ("<season> <league> teams list") instead.
- **It is August 2026** — European current season is 2026-27 (starting), calendar-year leagues are mid-2026. Agents record whichever season they verified per league.
- **WebSearch is capped at 200 calls per session, shared across ALL subagents** — 13 parallel research agents exhausted it in minutes; only ~35 of 211 associations got real data before the wall. Next time: run research agents sequentially with explicit per-agent budgets, or ask the user to raise CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION first.
- **npm/PyPI registries bypass the egress proxy** (noProxy allowlist) — but the only football dataset found there (football.json 1.0.0) is a 2015 snapshot; rejected as stale rather than passing it off as current.
- **Monte-Carlo the engine, don't eyeball it** — 300 headless careers (scripts/sim-career.mjs) exposed a 25% career-ending-injury rate and an event-pool exhaustion crash that a single browser playthrough missed. Run it after every engine change.
- **Node resolves imports from the script's path, not cwd** — test scripts using project deps must live inside the repo, not the scratchpad.
- **Playwright chromium lives at /opt/pw-browsers/chromium-1194/chrome-linux/chrome** — the bare /opt/pw-browsers/chromium dir is empty; don't trust the folder name.
- **Missing TSDB IDs in data are recoverable at runtime** — the player's browser is unrestricted, and TheSportsDB's all_leagues.php allows one cached name→id map covering leagues, cups and continental competitions, so trophy artwork works even though research-time ID harvesting was blocked.
- **Push needed the GitHub App installed, not just OAuth** — "Claude has not been installed on any accounts" on the settings page meant reads worked (OAuth) but writes 403'd; installing the app at github.com/apps/claude fixed it. Pages additionally needed a one-time Settings → Pages → Source = GitHub Actions, which the Actions token cannot set itself (`enablement: true` returns "Resource not accessible by integration").
- **WebSearch budget resets between user turns, not per session** — a later turn had a fresh 200 calls after an earlier one exhausted them. Re-check before assuming research is impossible; run agents with explicit hard caps (26 each worked well across 5 agents).
- **Fewer decision events starved reputation** — cutting to one decision per season collapsed international caps to a median of 0, because reputation only moved via events. Reputation now derives mainly from performance relative to league level. Check the sim's caps/World Cup counters after any change to event frequency.
- **Call-up threshold was inverted** — it made strong nations *easier* to break into than weak ones. Now `16 + natStr * 0.6`. Found only by questioning an implausible sim distribution, not by any test.
- **Weighted preference alone is too weak to express an intent** — nationality bias via weights still produced Nigerian offers for a Belgian. Reserving offer slots outright for home clubs (with a confederation fallback where the home league has no data) is what made it legible.
- **Verify designed-for behaviour with its own script** — scripts/check-nationality.mjs asserts the U-shaped home bias numerically; a screenshot alone would not have caught the weighting being too weak.
- **Guard additive edits with a diff against HEAD** — scripts/check-no-regression.mjs compares every league's club count to the last commit and fails on shrinkage. Essential when subagents modify existing files rather than create them; run it before every data commit.
- **Don't pad a league with a stale roster to make it playable** — Saint Lucia's only sourceable line-ups are from 2016-2018. Presenting those as the current season would misrepresent the data as surely as inventing clubs. Leave the file empty with a note saying what was found and when.
- **Coverage reached 203/211 playable associations.** The 8 that remain each have a documented reason: Liechtenstein has no domestic league (its clubs play in Switzerland), Pakistan's league is suspended, Palestine's runs but no current roster is published, and Dominica, Saint Lucia, Saint Vincent, Montserrat and the US Virgin Islands have semi-professional leagues with no sourceable current line-ups.

- **Word overlap cannot rank league names — the division marker is the whole signal.** "Serie A" scores identically against "Italian Serie A" and "Italy Serie D Girone A", and "Ligue 1" against "French Ligue 2", because tokens shorter than three characters were being dropped. Any name matcher over competitions has to compare the tier mark (1/2/3, A/B/C, I/II/III) explicitly and penalise a mismatch, or second divisions quietly wear top-flight crests.
- **Curated ids beat runtime matching where the set is small and known.** TheSportsDB's full soccer league list (~220 entries) is mirrored on GitHub and *is* reachable through the egress proxy even though thesportsdb.com is not — one fetch of `raw.githubusercontent.com/TralahM/thesportsdb/master/leagues.json` gave authoritative ids for every league the game ships. Check for a mirror before concluding an API is unreachable.
- **Scope a club search to its own league before searching the world.** `lookup_all_teams.php?id=<league>` returns one division's squads with badges, which is how "Hamburger SV" stops matching its own reserve side and a Belgian club stops matching a French one. Global name search is the fallback, not the first move.
- **Two rolls per decision is how text and numbers diverge.** The old cards rolled `resolve()` for the story and a separate `stake` for the OVR, so a triumphant paragraph could arrive with a rating cut. One roll picking between a `good` and a `bad` branch — with the OVR bound to the branch — makes the mismatch structurally impossible, and lets the card show the true odds.
- **Appearances need the club's actual fixture list, not a constant.** A flat `34 + irand(0,8)` ignored league size, cup runs and continental football; modelling `(n-1)*2` league games plus the rounds actually played put a first-choice player at ~92% of 38–52 fixtures and a fringe player at ~60% of far fewer. Measure share-of-fixtures by OVR band, not raw appearance counts, or league size hides the bug.
- **Empty-repo git log exits 128** — `git log` on a commitless branch is a normal failure, not a broken repo; check `ls` output before concluding anything.
- **Data schema before agents** — all research subagents get one canonical SCHEMA.md so 211 association files stay mergeable without rework.
